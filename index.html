Seguridad y Clave de Acceso

La app pide el PIN de 4 dígitos cada vez que se abre y al volver tras el tiempo de inactividad elegido abajo. Para cambiar el PIN, llena los tres campos; para cambiar solo el bloqueo automático, déjalos vacíos.

Datos del Negocio
Base de Datos Supabase (Plan Gratis) Desconectado

Conecta Supabase para respaldar todo en la nube y usar la misma información desde el celular y el computador. Los cambios se guardan primero en este dispositivo y se suben solos cuando hay internet.

Pasos: 1. En supabase.com ejecuta supabase_schema.sql (v2) en el SQL Editor de un proyecto nuevo. 2. En Authentication → Users → Add user crea el usuario del negocio (correo + contraseña, marcando "Auto Confirm"). Es el login de esta app, no el de tu cuenta de Supabase. 3. Pega aquí la URL y la Anon Key (Project Settings → API) y ese correo y contraseña. Todos los dispositivos del negocio usan el mismo usuario.
